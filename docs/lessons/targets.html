Global target properties

Not every requested shape can be obtained with a given robot, grasp, and object. Let \mathcal S\subseteq\R^n contain the feature vectors realizable under all robot, contact, object, and quasistatic constraints.

A target is feasible when \vs^*\in\mathcal S. It is reachable from the current state when an admissible manipulation path connects the current state to a state realizing \vs^*. Thus, a feasible target need not be reachable from every initial state—for example, it may lie on a disconnected equilibrium branch.

The schematic separates three cases: feasible and reachable, feasible but not reachable from the current state, and infeasible because the requested shape lies outside \mathcal S.

Local information is different

The Jacobian describes only the tangent directions currently available:

\dot{\vs}\in\Range(\vJ(\vq)).

It identifies locally producible feature changes, but cannot by itself prove global feasibility or the existence of an admissible path. With an exact Jacobian, the instantaneous feature error decomposes as

\ve=\underbrace{\vJ\vJ^{+}\ve}_{\ve_{\parallel}\in\Range(\vJ)}+\underbrace{(\mathbf I-\vJ\vJ^{+})\ve}_{\ve_{\perp}\in\Null(\vJ^{\top})}.

The controller can reduce \ve_{\parallel} locally. The orthogonal component is the local least-squares residual. With an estimated Jacobian, the displayed aqua/red split uses \vJh_k; the dashed curve in the component plot reports the exact reducible fraction for comparison.

The two running-example targets

The recorded target comes from another admissible gripper configuration, so it is feasible by construction. Convergence to zero in this trial also demonstrates that it is reachable from the tested initial state.

The second target is deliberately synthetic: three feature points are displaced beyond the rod's admissible deformation limits. Following the tutorial (Section IV-B, and Fig. S1 of its supplementary material), it is classified as infeasible, not merely “unreachable.” Its nonzero final error is a least-squares compromise.

  1. Use the global schematic to compare membership in \mathcal S with the existence of an admissible path. Notice that the dashed local \Range(\vJ) line answers neither global question.
  2. Run Feasible & reachable (recorded): the yellow points enter the grey rings and the error converges to zero.
  3. Run Infeasible (beyond limits): the error plateaus. Aqua arrows are the currently reducible component; red arrows are the locally non-reducible component.
  4. Switch on exact Jacobian. At the final compromise, the exact reducible fraction tends to zero and the residual lies in \Null(\vJ^{\top}).
  5. Drag a target ring. The edited target has no automatic global classification—the local split only reports what an infinitesimal motion can change now.

Feasibility and reachability are global properties; \Range(\vJ) is a local tangent space. A nonzero least-squares residual diagnoses locally non-reducible error, not by itself the global reason that the target was missed.
