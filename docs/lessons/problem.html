In the tutorial

Shape servoing is the automatic manipulation of a deformable object toward a desired shape. Let \vx denote the full configuration of the object, here the 25 nodes of the rod. Sensors provide measurements \vy, and a feature map \vs=f(\vy)\in\R^{n} extracts the shape representation used for control.

In the running example, perception tracks P=5 material points along the rod (yellow) and stacks their image coordinates as \vs=[x_1,y_1,\dots,x_5,y_5]^{\top}, so n=10. Given the target \vs^{*} (grey rings on the dashed shape), the shape error is

\ve(t)=\vs^{*}-\vs\big(\vy(t)\big).

Each arrow on the rod shows the error of one point, that is, two entries of \ve.

The robot coordinates are the gripper poses \vq=[x_L,y_L,\theta_L,x_R,y_R,\theta_R]^{\top}, so m=6. Manipulation is quasistatic: after a small robot motion, the rod settles to the equilibrium that minimizes its total potential energy, so the features can be written as \vs=\vs(\vq).

Try this

  1. Drag the left gripper (violet) and note which error arrows change the most.
  2. Drag the ring above a gripper to rotate it, which changes \theta_L or \theta_R. Drag the rod itself to move both grippers together.
  3. Reduce \norm{\ve} below 10% of its initial value by hand, and count the corrections you need.
  4. Compare the dimensions: m=6 robot coordinates and n=10 error entries.

The controller uses only the reduced description \vs, not \vx. To reduce \ve without trial and error, it needs the relation between robot motion and the change of \vs: the deformation Jacobian of Demo 02.

Correspondence and the scope of the tutorial

Coordinate-based features require a consistent correspondence between the current and target representations: corresponding entries of \vs and \vs^{*} refer to the same material locations throughout the deformation.

The tutorial assumes quasistatic, velocity-level manipulation; measurable shape feedback; and a continuous manipulation regime, in which contacts, topology, and the deformation regime do not change discontinuously during the task.
