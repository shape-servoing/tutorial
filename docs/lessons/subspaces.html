The local geometry behind Sections IV-B and IV-C

The deformation Jacobian maps robot velocity to feature velocity, \dot{\vs}=\vJ\vu. Its four fundamental subspaces answer two different questions:

SpaceActive directionsNull directions
feature space \R^n\Range(\vJ): locally producible feature changes\Null(\vJ^{\top}): locally non-reducible error
robot space \R^m\Range(\vJ^{\top}): motion that changes the task\Null(\vJ): motion invisible to the selected features

Feature error when n > m

With ten point-coordinate features and six robot DoFs, the exact local error decomposition is

\ve=\underbrace{\vJ\vJ^{+}\ve}_{\ve_{\parallel}\in\Range(\vJ)}+\underbrace{(\mathbf I-\vJ\vJ^{+})\ve}_{\ve_{\perp}\in\Null(\vJ^{\top})}.

The pseudoinverse command reacts only to \ve_{\parallel}. The orthogonal component satisfies \vJ^{\top}\ve_{\perp}=\mathbf0 and remains as the local least-squares residual. This is a local statement: the tangent space does not by itself establish global target feasibility or reachability.

Robot motion when n < m

Sections II–IV of the tutorial use point-coordinate features. Tracking only two points gives \vs=[x_1,y_1,x_2,y_2]^{\top}, so n=4<m=6, and a robot motion decomposes as

\dq=\underbrace{\vJ^{+}\vJ\dq}_{\dq_{\mathrm{task}}\in\Range(\vJ^{\top})}+\underbrace{(\mathbf I-\vJ^{+}\vJ)\dq}_{\dq_{\mathrm{null}}\in\Null(\vJ)}.

The red ghost motion changes the grippers and the untracked parts of the rod, but the first-order displacement of both tracked points is zero. Such null-space freedom can support secondary tasks without disturbing the selected point-position task locally. Richer shape descriptors are introduced later, in Section VI.

Try this

  1. In Feature error, set the non-reducible component to zero. The target error lies entirely in \Range(\vJ) and the aqua arrows (reducible component) reach every target ring.
  2. Restore the red component, then set the reducible component to zero. The pseudoinverse command becomes zero even though the feature error is nonzero.
  3. Switch to Two points. Set the task-producing motion to zero and increase the null motion: the grippers move, while the displacement of the two tracked points stays near zero.
  4. Combine both robot-motion components and verify geometrically that they add orthogonally in the lower diagram.

\Range(\vJ) and \Null(\vJ^{\top}) split feature error; \Range(\vJ^{\top}) and \Null(\vJ) split robot motion. These local subspaces explain both least-squares residuals and redundant motions that preserve the selected point positions.
