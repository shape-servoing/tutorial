In the tutorial

Given the estimate \vJh, the controller maps the shape error to a robot velocity using the Moore–Penrose pseudoinverse:

\vu=\alpha\,\vJh^{+}\ve,

where \alpha>0 is the control gain. Under the estimated model, this command yields the feature velocity \vJh\vu=\alpha\,\vJh\vJh^{+}\ve, the orthogonal projection of \alpha\ve onto \Range(\vJh). When n>m and \vJh has full column rank, as here, \vJh^{+}=(\vJh^{\top}\vJh)^{-1}\vJh^{\top}, and the command minimizes the least-squares error in feature space.

At iteration k, the robot applies \vu_k=\alpha\,\vJh_k^{+}\ve_k over one control period, producing \dq_k=\vu_k\Delta t. Each command and the measured feature change form an action–response pair, so the loop generates the data needed to update the estimate without additional probing. With the prediction error \vr_k=\ds_k-\vJh_{k-1}\dq_{k-1}, Broyden's rule corrects the estimate as

\vJh_k=\vJh_{k-1}+\frac{\vr_k\,\dq_{k-1}^{\top}}{\dq_{k-1}^{\top}\dq_{k-1}}.

The update enforces the secant relation \vJh_k\dq_{k-1}=\ds_k with the smallest Frobenius-norm change to \vJh_{k-1}. The correction has magnitude \norm{\vr_k}/\norm{\dq_{k-1}}, so practical implementations skip the update below a minimum \norm{\dq_{k-1}} and reject implausibly large corrections.

With the exact Jacobian, the error decays as (1-\alpha\Delta t)^k. The running example uses \Delta t=1, so the dotted line in the error plot is (1-\alpha)^k.

Try this

  1. Press Run with \alpha=0.05 and the online update on: the error closely follows the nominal decay and converges.
  2. Press Reset, switch the online update off, and run again. With \vJh_0 held fixed, the error does not converge and ends above its initial value, because \vJh_0 no longer gives a descent direction once the rod has moved away from the configuration where it was identified.
  3. Set \alpha=0.35: larger motions leave the region where the local model is accurate, and the error first rises above its initial value before converging.
  4. Press Step to execute one iteration of Algorithm 1 line by line, including the rank-one correction of the estimate.
  5. Pause, drag the grippers to a new shape, and choose Record current: the target is now specified by demonstration, and the run restarts from \vq_0.

The loop alternates between updating the local Jacobian estimate and using it for feedback. The online update keeps the estimate representative as the object deforms, and the gain must keep each motion within the region where the estimate is accurate.
