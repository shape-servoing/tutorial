In the tutorial

Because the shape features depend on the object configuration, which in turn depends on the robot coordinates, the chain rule gives the deformation Jacobian

\vJ(\vq)=\frac{\partial \vs}{\partial \vx}\frac{\partial \vx}{\partial \vq}=\frac{\partial \vs}{\partial \vq}\in\R^{n\times m}.

The factor \partial\vx/\partial\vq describes how robot motion changes the object configuration, and \partial\vs/\partial\vx how these changes are reflected in the selected features. With \dot{\vq}=\vu, the local input–output relation becomes

\dot{\vs}=\vJ(\vq)\dot{\vq}=\vJ(\vq)\vu.

The jth column of \vJ is the feature velocity produced by a unit velocity of robot coordinate q_j. In the running example, \vJ\in\R^{10\times6}, and for a small increment \ds\approx\vJ\dq.

Unlike in visual servoing, \vJ is not determined solely by a known geometric projection, but also by the configuration-dependent mechanical response of the object: the same gripper motion can produce very different shape changes when the rod is slack and when it is taut.

Try this

  1. Click the \theta_L column of \vJ. Which tracked points does a rotation of the left wrist move the most?
  2. Increase \dq until the predicted arrows \vJ\dq and the measured changes \ds separate (see the legend). The plot shows the linearization error growing with the step size.
  3. Switch between Slack and Taut with the same \dq, and compare the responses and the columns of \vJ.
  4. Drag a gripper: \vJ is recomputed at each configuration.

\vJ is a local model: accurate for small motions around the current configuration, and different at every configuration. The demo computes it exactly from the simulation; on a real system it is unknown and must be estimated from data (Demo 03).

How the demo computes J

Each column j is a central difference of the simulated equilibrium, \big(\vs(\vq+\varepsilon\mathbf{e}_j)-\vs(\vq-\varepsilon\mathbf{e}_j)\big)/2\varepsilon with \varepsilon=10^{-3}, which requires evaluating the simulation without moving the robot. Applied to a mechanical model \vg:\vq\mapsto\vs, the same function gives the model-based initial estimate of the tutorial.
