The local question after feasibility

For a constant target, the estimated-Jacobian controller gives

\dot{\ve}=-\alpha\vJ\vJh^{+}\ve, \qquad \dot{\mathcal L}=-\alpha\ve^{\top}\vJ\vJh^{+}\ve, \quad \mathcal L=\tfrac12\norm{\ve}^2.

The arrows compare the error \ve with the feature velocity \vJ\vJh^{+}\ve actually produced by the estimated inverse. An angle below 90° gives instantaneous descent for that error; an angle above 90° gives ascent.

The paper's n > m condition

The running example has n=10 feature coordinates and m=6 robot DoFs, with maximum column rank. The sufficient condition in Section IV-C is

\Sym(\vJh^{+}\vJ)\succ0 \quad\text{on }\Range(\vJ^{\top}).

Here \Sym(A)=\tfrac12(A+A^{\top}). When it holds, all controllable modes converge locally and the feature error approaches a residual in \Null(\vJh^{\top}). The eigenvalue bars test the condition directly; the angle fan checks 600 sampled errors in \Range(\vJ). The condition is sufficient, not necessary: a negative smallest eigenvalue means that some direction lacks a guarantee, not that every run diverges.

Try this

  1. Set the scale to c=5. The relative matrix error is 400%, but every eigenvalue remains positive and the run converges more slowly.
  2. Rotate the y_L and \theta_L columns into each other (angle \gamma). Watch the smallest eigenvalue of \Sym(\vJh^{+}\vJ) cross zero and compare it with the sampled descent angles.
  3. Flip one column or add random perturbation. Matrix error measures numerical disagreement; the restricted symmetric part tests whether corrective directions are preserved.
  4. With the exact estimate, raise \alpha toward 2 and compare the run with the dotted exact-\vJ rate |1-\alpha|^k in the error plot: for \alpha>1 the rod overshoots and oscillates while settling.
  5. Generate several nearby targets after making the sufficient condition fail. Some trajectories may still converge, illustrating why the condition is sufficient rather than necessary.

Feasibility and reachability ask whether the target can be realized and whether an admissible path reaches it. Local stability asks whether the estimated inverse preserves the true corrective directions near the operating point. Neither question replaces the other.

Estimate accuracy is not the stability test

The condition can hold even when \norm{\vJ-\vJh}_F is large. If \vJh=c\vJ with c>0, then \vJh^{+}\vJ=(1/c)\mathbf I on the controllable robot directions: the rate changes, but the directions remain corrective.

The guarantee is local. The Jacobian, its rank, the contact state, and the object mechanics may change along a large manipulation. In discrete time, exact maximum-rank control gives the familiar controllable-mode condition 0<\alpha\Delta t<2.

How the demo worsens the estimate

The exact \vJ is computed at the start configuration. The demo forms \vJh=c\vJ\mathbf R_{\gamma}+\varepsilon\norm{\vJ}_F\mathbf N/\norm{\mathbf N}_F, where \mathbf R_{\gamma} rotates two robot-coordinate columns into each other and \mathbf N is fixed random noise; a selected column may also be sign-flipped. The loop then holds \vJh fixed while pursuing a target generated by a nearby admissible robot configuration.
