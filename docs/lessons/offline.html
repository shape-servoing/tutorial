In the tutorial

The control law requires an initial Jacobian estimate \vJh_0. To obtain it, the robot applies small perturbations around its initial configuration \vq_0 along a set of independent actuation directions. For C exploratory motions, the action and response of motion c are \dq_c=\vq_c-\vq_0 and \ds_c=\vs_c-\vs_0, stacked as the columns of \dQ\in\R^{m\times C} and \dS\in\R^{n\times C}. For sufficiently small motions, \ds_c\approx\vJ\dq_c, so the initial estimate is obtained by least-squares regression:

\vJh_0=\arg\min_{\vJ}\big\lVert \dS-\vJ\dQ \big\rVert_F^2=\dS\dQ^{+}.

If the exploratory motions span the input space, \dQ has full row rank and the solution is unique. The probing amplitude must be small enough for \ds_c\approx\vJ\dq_c to remain valid, yet large enough for the feature changes to exceed measurement noise. The residual \norm{\dS-\vJh_0\dQ}_F quantifies how well a single linear map explains the collected responses.

In the running example, four signed perturbations along each of the six gripper DoFs give C=24 pairs, and \dQ is block diagonal. The residual \approx0.31 is about 18\% of \norm{\dS}_F\approx1.72, and \vJh_0 has full column rank and a condition number of about 17.

Try this

  1. Press Probe & fit with the default settings: the residual is about 18% of \norm{\dS}_F.
  2. Increase the amplitude to ×3: the residual grows, because a single linear map no longer fits the larger, nonlinear responses.
  3. Add measurement noise and reduce the amplitude: the error of \vJh_0 grows. Sweep amplitudes shows the trade-off between the two effects.
  4. With one probe per coordinate (C=6), the residual is zero, yet \vJh_0 is not exact.
  5. In the model card, change the bending stiffness or the weight of the model rod: the model-based estimate requires no probing but inherits the model error.

A small residual supports the estimate only near \vq_0. As the object deforms, the estimate must be updated (Demo 04).

Initialization from a model

The Jacobian estimate can also be informed by a mechanical, geometric, or learned model of the object–robot system, either analytically or by applying small perturbations to the model and measuring the predicted feature changes. The model-derived estimate can initialize \vJh_0 and then be refined online with the Broyden update. Relating the model to the robot and perception system may require camera calibration, object geometry and mechanical parameters, grasp locations and constraints, and the available actuation DoFs, whose errors also affect the estimate.
